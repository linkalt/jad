# sample/jad

File-shape examples (profiles, models, tools, MCP, sandboxes, sessions) and the catalog fixture that the Go tests copy.
It is not a startable workspace: JAD starts only in a folder with `.jad/workspace.json` (see `docs/design_workspace_layout.md`).
`sample/workspace-layout` holds the examples for the global side (a remote binding and its key file), not a whole workspace.
